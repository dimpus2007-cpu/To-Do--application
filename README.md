# 📝 To-Do My Work

A simple, responsive and user-friendly To-Do application built using HTML, CSS and JavaScript.

The application helps users organize daily tasks, track completed work and manage tasks easily.

## ✨ Features

- ➕ Add new tasks
- ⌨️ Add tasks using the Enter key
- ☑️ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔍 Filter tasks by All, Active and Completed
- 🧹 Clear completed tasks
- 🔢 Active task counter
- 💾 Tasks are saved using LocalStorage
- 📱 Responsive design for desktop and mobile devices
- 🎨 Modern dark-themed user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `INDEX.HTML` using a browser or VS Code Live Server.
4. Start adding and managing your tasks.

## 💡 How It Works

Tasks are created and managed using JavaScript.

The application uses **LocalStorage** to save tasks in the browser, so your tasks remain available even after refreshing the page.

## 📱 Responsive Design
